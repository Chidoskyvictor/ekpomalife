Put the game music here.

  theme.mp3     (required)  plays first and loops through the list
  theme-2.mp3   (optional)
  theme-3.mp3   (optional)
  theme-4.mp3   (optional)

MP3, made to loop cleanly, about 1-2 MB each (the game decodes the whole song into memory).
Optional: an .ogg (~96 kbps) with the same name next to it is used first.
Missing files are skipped.
