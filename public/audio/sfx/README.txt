Sound effects go here. Short clips, .mp3 (an .ogg with the same name is only a fallback if the .mp3 is missing).
Keep each under ~50 KB; a missing file is simply skipped. Full list: SFX in lib/audio/sfx.ts.

  tap        any button, link or tab           (soft click, ~50 ms)
  back       back / close / cancel             (lower, softer click)
  toggle     switch or checkbox                (on/off flick)
  open       sheet, menu, phone opening        (short whoosh up)
  close      sheet or menu closing             (short whoosh down)
  error      failed form, rejected action      (low buzz / "nope")
  success    action worked (green toast)       (bright two-note ping)
  notify     info notice, message arriving     (gentle bell)
  sent       chat message sent                 (soft swoosh)
  coin       money received                    (coin clink)
  spend      money paid                        (till / coin drop)
  signup     account created                   (short fanfare, ~1.5 s)
  login      signed in                         (welcome chime)
  spin       starting-money reels spinning     (slot-machine roll, ~2 s)
  reveal     reels land                        (ta-da / jackpot hit)
  celebrate  confetti, dream complete, grade A (party horn + cheer)
  arrive     trip finished                     (arrival ding)
  card-play  Whot card played                  (card slap)
  card-draw  Whot card picked up               (card slide)
  win        game won                          (victory jingle)
  lose       game lost                         (sad trombone, short)
  spray      club: money sprayed               (cash-gun flutter)
  grab       club: note grabbed                (quick pop)
