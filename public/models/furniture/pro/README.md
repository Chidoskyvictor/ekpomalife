# Textured furniture (pro)

Built by `scripts/models/build-pro.mjs` from CC0 sources (Poly Haven models, ambientCG textures). Real-world metres, floor-centred, +Y up, front = +Z. Base-colour texture only. Materials whose name ends in `_fixed` carry `extras.notint` and keep their colour when a finish is applied (wood, metal, screens); everything else is tinted by the finish.
